# Рецепт - React.js

React застосування для відображення рецепту картопляного пюре з компонентами.

## Запуск

```powershell
npm install
npm run dev
```

Сервер відкриється на `http://localhost:5174`

## Компоненти

- **App** — головний компонент
- **Recipe** — компонент з інгредієнтами
- **Steps** — компонент з кроками приготування
