# React.js Projects

Два проекти React для навчання.

## Проекти

### 1. hello-world/
Просте "Hello, World!" застосування з компонентом та динамічними даними.

```powershell
cd hello-world
npm install
npm run dev
```

### 2. recipe-app/
Застосування з рецептом картопляного пюре та кількома компонентами.

```powershell
cd recipe-app
npm install
npm run dev
```

## Технологія

- React 18
- Vite (bundler)
- CSS
