# Hello World - React.js

Просте React застосування з компонентом та динамічними даними.

## Запуск

```powershell
npm install
npm run dev
```

Сервер відкриється на `http://localhost:5173`

## Компоненти

- **Greeting** — основний компонент з привітанням

## Функціональність

- ✅ JSX синтаксис
- ✅ Динамічні дані (змінні у компоненті)
- ✅ CSS стилізація
- ✅ Vite як bundler
